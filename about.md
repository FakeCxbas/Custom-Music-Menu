# Custom Menu Music

A simple mod for Geometry Dash that lets you choose any custom song (.mp3, .ogg, .wav) to play on the main menu.

## Features

- **Any audio file:** Choose any `.mp3`, `.ogg`, or `.wav` from your files.
- **Texture pack support:** Uses native circle buttons so it matches whatever texture pack you have installed.
- **In-game file picker:** Pick songs directly through Geode's settings without manually replacing game files.
- **Instant reload:** Changing the song or toggling the mod updates the music immediately without restarting GD.
- **Notifications:** Optional popup showing the song title when it starts playing.
- **Bilingual:** Supports English and Spanish for notifications.

## How to use

1. Click the music note button on the bottom bar of the main menu (or open Geode -> Mods -> Custom Menu Music -> Settings).
2. Browse and select your audio file.
3. The song will start playing right away.
