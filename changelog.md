# Changelog

## v1.0.0
* Initial release of **Custom Menu Music**!
* Set any custom audio track (`.mp3`, `.ogg`, `.wav`) for the main menu.
* Native texture pack compatibility using `CircleButtonSprite`.
* In-game file picker & instant music reload.
* Multi-language support (English and Español).
* Optional "Now Playing" toast notification.
* Quick access button on the main menu bottom bar.
